# 03 — LLM/CNF Hybrid: Text-Conditioned Galaxy Generation (Postponed)

Training a Continuous Normalizing Flow conditioned on semantic text embeddings
to enable controlled galaxy morphology synthesis from natural language descriptions.
An optional extension of Stage 02, built on the same Galaxy10 DECaLS dataset.

---

## Goals

- Build a text-to-image generation pipeline without a diffusion model or GAN
- Condition the CNF vector field directly on dense semantic embeddings
- Investigate whether natural language is an expressive enough conditioning
  signal to steer galaxy morphology at inference time
- Quantify that expressiveness with an independent morphology classifier rather
  than judging samples by eye

---

## Pipeline

### 1 Caption Generation

Per-image natural language captions are generated from raw galaxy images using
**Qwen3-VL 7B**, producing rich textual descriptions of morphology, structure,
and visual features for each sample in the dataset.

### 2 Text Embedding

Captions are encoded into dense **384-dimensional embedding vectors** via
**Snowflake Arctic Embed S** (33M parameters), chosen for its semantic
similarity properties and its small model size — images with similar
morphologies should have nearby embeddings, and the lightweight footprint keeps
the pipeline tractable alongside the CNF training.

### 3 Conditioned CNF

A CNF is trained (Flow Matching objective) to learn the mapping from a Gaussian
prior directly to 64×64 pixel space, with the text embedding injected into the
vector field `v(x, t, c)` via **FiLM conditioning**. FiLM was never combined
with Flow Matching in the earlier stages, so this stage is also a direct test of
whether FiLM conditioning is stable and effective under the FM objective —
during training the field is evaluated at random `t`; at inference the same
conditioned field is used at every solver step.

### 4 Controlled Generation

At inference time, galaxy images are generated by integrating the learned ODE
from noise to data, guided by a text prompt — allowing morphology control
without retraining.

### 5 Evaluation

Prompt-following is measured with an independent CNN morphology classifier
([`CNN-galaxy-classifier.ipynb`](./CNN-galaxy-classifier.ipynb)), trained on
Galaxy10 during a prior exam project and reused here as a fixed, external judge.
The protocol:

- Take a real galaxy with a known class label and its generated caption.
- Generate a new image conditioned on that caption.
- Classify the generated image with the CNN.
- **Prompt-following accuracy** = fraction of generated images whose predicted
  class matches the source image's true class.

Comparing this against unconditional generation — which only reproduces the
class prior — makes the result falsifiable: if conditioned accuracy sits
significantly above the unconditional/class-prior baseline, the text embedding
carries real morphological information; if not, natural language is not an
expressive enough signal at this scale.
