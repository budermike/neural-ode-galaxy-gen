# 03 — LLM/CNF Hybrid: Text-Conditioned Galaxy Generation (Postponed)

Training a Continuous Normalizing Flow conditioned on semantic text embeddings
to enable controlled galaxy morphology synthesis from natural language descriptions.
An optional extension of Stage 02, built on the same Galaxy10 DECaLS dataset.

---

## Goals

- Build a text-to-image generation pipeline without a diffusion model or GAN
- Condition the CNF vector field directly on dense semantic embeddings
- Investigate whether natural language is an expressive enough conditioning
  signal to steer galaxy morphology at inference time

---

## Pipeline

### 1 Caption Generation

Per-image natural language captions are generated from raw galaxy images using
**Qwen3-VL 7B**, producing rich textual descriptions of morphology, structure,
and visual features for each sample in the dataset.

### 2 Text Embedding

Captions are encoded into dense **768-dimensional embedding vectors** via
**Snowflake Arctic Embed 33M**, chosen for its semantic similarity properties
and its small model size — images with similar morphologies should have nearby
embeddings, and the lightweight footprint keeps the pipeline tractable alongside
the CNF training.

### 3 Conditioned CNF

A CNF is trained to learn the mapping from a Gaussian prior directly to
64×64 pixel space, with the text embedding injected as a conditioning signal
into the ODE vector field at each integration step.

### 4 Controlled Generation

At inference time, galaxy images are generated by integrating the learned ODE
from noise to data, guided by a text prompt — allowing morphology control
without retraining.
